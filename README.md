# e-plantShopping

## Paradise Nursery Shopping Application

**Repository Name:** `e-plantShopping`

Paradise Nursery is a React-based shopping cart application for an online plant nursery. The application allows users to browse different categories of house plants, view plant information, add plants to a shopping cart, and manage quantities of items in the cart.

## Features

* Landing page for Paradise Nursery
* Navigation bar with Home, Plants, and Cart links
* Plant products organized into different sections
* Plant images, names, descriptions, and prices
* Add plants to the shopping cart
* Increase and decrease plant quantities
* Remove plants from the cart
* Display individual item totals
* Display the overall cart total
* Continue Shopping functionality
* Checkout functionality

## Technologies Used

* React
* JavaScript
* Redux Toolkit
* HTML
* CSS
* Vite

## Project Purpose

This project demonstrates the use of React components, React Hooks, Redux state management, dynamic rendering, event handling, and conditional rendering to build a functional shopping cart application.
